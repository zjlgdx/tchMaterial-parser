# 国家中小学智慧教育平台资源下载工具 - 现代化架构设计方案

## 1. 技术栈选择

### 核心技术
- **Python 3.10+** - 使用现代Python特性（类型注解、dataclass、match-case等）
- **GUI框架**: 
  - 主选：**CustomTkinter** - 现代化的Tkinter封装，更美观
  - 备选：**PyQt6** / **Kivy** - 功能更强大但体积较大
- **异步框架**: **asyncio** + **aiohttp** - 替代requests，提供更好的并发下载
- **配置管理**: **Pydantic** - 类型安全的配置管理
- **日志**: **loguru** - 简单强大的日志库
- **打包**: **PyInstaller** / **Nuitka** - 生成独立可执行文件

### 依赖管理
- 使用 **Poetry** 管理依赖
- 使用 **pyproject.toml** 替代 requirements.txt

### 3.4 下载器 (core/downloader.py)

```python
import asyncio
from pathlib import Path
from typing import Callable, Optional
import aiohttp
from loguru import logger
from ..models.download import DownloadTask, DownloadStatus

class Downloader:
    def __init__(self, settings):
        self.settings = settings
        self.tasks: Dict[str, DownloadTask] = {}
        self._semaphore = asyncio.Semaphore(settings.max_concurrent_downloads)
        
    async def download(
        self, 
        url: str, 
        save_path: Path,
        task_id: str,
        progress_callback: Optional[Callable] = None
    ) -> DownloadTask:
        """下载文件"""
        task = DownloadTask(
            id=task_id,
            url=url,
            save_path=save_path,
            status=DownloadStatus.PENDING
        )
        self.tasks[task_id] = task
        
        async with self._semaphore:
            try:
                await self._download_file(task, progress_callback)
                task.status = DownloadStatus.COMPLETED
            except Exception as e:
                task.status = DownloadStatus.FAILED
                task.error = str(e)
                logger.error(f"Download failed: {e}")
                
        return task
        
    async def _download_file(
        self, 
        task: DownloadTask,
        progress_callback: Optional[Callable]
    ):
        """实际下载逻辑"""
        headers = {}
        if self.settings.access_token:
            headers["X-ND-AUTH"] = f'MAC id="{self.settings.access_token}",nonce="0",mac="0"'
            
        async with aiohttp.ClientSession() as session:
            async with session.get(task.url, headers=headers) as response:
                response.raise_for_status()
                
                task.total_size = int(response.headers.get('Content-Length', 0))
                task.status = DownloadStatus.DOWNLOADING
                
                with open(task.save_path, 'wb') as file:
                    async for chunk in response.content.iter_chunked(self.settings.chunk_size):
                        file.write(chunk)
                        task.downloaded_size += len(chunk)
                        
                        if progress_callback:
                            await progress_callback(task)
```

### 3.6 存储管理 (utils/storage.py)

```python
import json
from pathlib import Path
from typing import Dict, Any
import platform
from loguru import logger

class StorageManager:
    def __init__(self, config_dir: Path):
        self.config_dir = config_dir
        self.config_dir.mkdir(parents=True, exist_ok=True)
        self.config_file = self.config_dir / "config.json"
        
    def save_config(self, config: Dict[str, Any]):
        """保存配置"""
        try:
            with open(self.config_file, 'w', encoding='utf-8') as f:
                json.dump(config, f, indent=2, ensure_ascii=False)
        except Exception as e:
            logger.error(f"Failed to save config: {e}")
            
    def load_config(self) -> Dict[str, Any]:
        """加载配置"""
        if not self.config_file.exists():
            return {}
            
        try:
            with open(self.config_file, 'r', encoding='utf-8') as f:
                return json.load(f)
        except Exception as e:
            logger.error(f"Failed to load config: {e}")
            return {}
            
    def save_token(self, token: str):
        """保存Access Token"""
        if platform.system() == "Windows":
            self._save_token_windows(token)
        else:
            config = self.load_config()
            config["access_token"] = token
            self.save_config(config)
```
